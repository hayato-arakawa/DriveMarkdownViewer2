## 📦 Drive Markdown Viewer 拡張

### ファイル構成
| ファイル | 説明 |
|---|---|
| [manifest.json](file:///Users/arakawa/brico/chrome-md-addon/manifest.json) | Manifest V3 設定 |
| [content.js](file:///Users/arakawa/brico/chrome-md-addon/content.js) | メインのコンテンツスクリプト |
| [content.css](file:///Users/arakawa/brico/chrome-md-addon/content.css) | ダークテーマのスタイル |
| [background.js](file:///Users/arakawa/brico/chrome-md-addon/background.js) | ファイル取得用Service Worker |
| [lib/marked.min.js](file:///Users/arakawa/brico/chrome-md-addon/lib/marked.min.js) | Markdownパーサー (v15.0.7) |
| [lib/purify.min.js](file:///Users/arakawa/brico/chrome-md-addon/lib/purify.min.js) | XSS対策サニタイザー (v3.2.5) |

### 機能
1. **トグルボタン**: Google Driveのファイルプレビュー画面のツールバー（「Google ドキュメント で開く」「共有」と同じ列）に **「MD」ボタン** を追加
2. **Markdownレンダリング**: GFM（GitHub Flavored Markdown）対応。テーブル、コードブロック、タスクリスト等をサポート
3. **トグル切り替え**: ボタンクリックでMarkdownプレビューと元の表示を切り替え
4. **セキュリティ**: DOMPurifyでサニタイズ済みのHTMLを表示
5. **ESCキー** で閉じる

### インストール方法
1. Chromeで `chrome://extensions` を開く
2. 右上の「デベロッパーモード」をON
3. 「パッケージ化されていない拡張機能を読み込む」をクリック
4. `/Users/arakawa/brico/chrome-md-addon` フォルダを選択
5. Google Driveで `.md` ファイルを開いてテスト

### 注意点
- Google Driveのツールバー要素は動的に生成されるため、`MutationObserver`で出現を監視しています
- `aria-label`やdata属性ベースのセレクタを使用していますが、Googleの仕様変更で調整が必要になる可能性があります
- 実際のGoogle Driveページで動作確認し、セレクタの微調整が必要な場合はお知らせください
