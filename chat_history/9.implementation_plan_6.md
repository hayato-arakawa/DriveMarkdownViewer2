# Chrome Extension for Google Drive Markdown Preview

Create a Chrome extension that targets `https://drive.google.com/file/*` pages, extracts markdown text from Google Drive's preview `<pre>` element, parses it using a markdown parser (`marked.js`), and displays a beautifully styled, interactive markdown rendering.

## User Review Required

> [!IMPORTANT]
> The selector provided for the preview element is very specific and fragile:
> `body > div.YM5U3.dif24c... > span > span > div:nth-child(2) > div > div.ndfHFb-c4YZDc-K9a4Re > div.ndfHFb-c4YZDc-K9a4Re-nKQ6qf.ndfHFb-c4YZDc-TvD9Pc-qnnXGd > div.ndfHFb-c4YZDc-oKVyEf > div > div > div.ndfHFb-c4YZDc-fmcmS > div > div > div > pre`
>
> We will implement a multi-stage selector strategy in the content script:
> 1. Try to find the element using the exact selector provided.
> 2. Fall back to a resilient selector (e.g., finding the `<pre>` element inside the standard Google Drive viewer class `ndfHFb-c4YZDc-K9a4Re` or similar container).
> 3. Provide log information in the developer console to ease troubleshooting if Google changes their DOM classes.

## Proposed Changes

We will create a Manifest V3 Chrome Extension containing the following files:

### Chrome Extension Structure

#### [NEW] [manifest.json](file:///Users/arakawa/chrome-md-addon/manifest.json)
Declares extension metadata, permissions for `https://drive.google.com/file/*`, and content scripts (`marked.min.js`, `content.js` and `styles.css`).

#### [NEW] [marked.min.js](file:///Users/arakawa/chrome-md-addon/marked.min.js)
The local bundled Markdown parser library (loaded before `content.js` to ensure script safety and offline compliance under MV3).

#### [NEW] [content.js](file:///Users/arakawa/chrome-md-addon/content.js)
Contains:
1. **Dynamic Selector Waiting**: A `MutationObserver` combined with interval polling to wait for the dynamic Google Drive preview `<pre>` container to render.
2. **Parsing & Rendering Logic**: Extracts the text content, parses it via `marked.parse()`, and renders it in a custom overlay or replaced container.
3. **Interactive UI Utilities**: 
   - A modern floating Toggle Button to switch between **Raw Text** and **Markdown View**.
   - Copy-to-clipboard functionality for code blocks.
   - Dynamic dark/light mode alignment to match Google Drive's dark theme if enabled, or a custom togglable stylesheet.

#### [NEW] [styles.css](file:///Users/arakawa/chrome-md-addon/styles.css)
Styles the parsed HTML with a premium, sleek GitHub-style markdown aesthetic combined with a glassmorphism floating menu:
- Curated typography (using Inter/system sans-serif)
- Code blocks with syntax formatting, syntax highlighting styling, and subtle borders
- Table stylings, quote blocks, list spacings
- Floating dashboard for raw/markdown view switching
- Animations for layout transitions
