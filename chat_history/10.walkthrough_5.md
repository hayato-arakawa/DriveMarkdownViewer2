## Load Instructions

To install and load the extension in Google Chrome:

1. Open **Google Chrome**.
2. Navigate to the extensions page by entering `chrome://extensions/` in the URL bar.
3. Turn on the **Developer mode** toggle in the top-right corner of the page.
4. Click on the **Load unpacked** button in the top-left corner.
5. In the file picker, select the workspace folder:
   `/Users/arakawa/chrome-md-addon`
6. The extension **"Google Drive Markdown Viewer"** is now loaded!

## How to Verify & Features

1. Open any Markdown or text file preview link on Google Drive (e.g., `https://drive.google.com/file/d/YOUR_FILE_ID/view`).
2. You will see a modern **Markdown Preview** rendered directly in place of the raw text box:
   - **Markdown Rendering**: Fully parsed headers, lists, text formatting, bolding, blockquotes, links, and custom styled tables.
   - **Interactive View Toggle**: A toolbar at the top allows you to switch seamlessly between the parsed **Markdown** and the original **Raw Text**.
   - **Custom Light/Dark Theme switcher**: Click the **🌓 Theme** button in the toolbar to switch the markdown stylesheet between light mode and dark mode.
   - **Floating Copy Button**: Hover over any code block (`pre code`) to reveal a premium floating **Copy** button. Clicking it copies the block content directly to your clipboard and provides instant checkmark feedback.
3. If the file's content loads incrementally or updates, the content script automatically detects the mutation and refreshes the rendering.
