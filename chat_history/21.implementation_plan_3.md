# Drive Markdown Viewer Implementation Plan

Implement a Google Chrome Manifest V3 extension to render Markdown (.md / .markdown) files beautifully in Google Drive's file preview window.

## User Review Required

> [!IMPORTANT]
> **Host Permissions:**
> To fetch file contents via the background script when DOM scraping fails, the extension requires access to `https://drive.google.com/*` and `https://docs.google.com/*`. These permissions will use existing user session cookies.
>
> **Third-Party Libraries:**
> We will bundle official minified releases of `marked.js`, `DOMPurify`, and `highlight.js` to ensure the extension is offline-capable and passes Chrome Web Store security reviews.

## Proposed Changes

We will create a Google Chrome Extension in `/Users/arakawa/brico/md-addon/` with the following structure:

### Configuration

#### [NEW] [manifest.json](file:///Users/arakawa/brico/md-addon/manifest.json)
Configure Manifest V3 Chrome Extension. Specify content scripts targeting `https://drive.google.com/file/d/*/view*`, with dependencies and core styles. Request `activeTab` and host permissions for `drive.google.com` and `docs.google.com` to allow the background script to perform background file downloads.

### Core Logic

#### [NEW] [content.js](file:///Users/arakawa/brico/md-addon/content.js)
The main content script. It will:
- Monitor DOM using a `MutationObserver` (up to 30 seconds) to find and insert the "MD" toggle button into the Google Drive toolbar.
- Safely scrape the raw Markdown content using a hierarchy of fallback selectors (`pre[role="presentation"]`, `div.a-b-r pre`, text pages, styling cues).
- Call the background script to fetch the file contents if the DOM doesn't contain the raw Markdown text.
- Render Markdown using `marked.js`, sanitize using `DOMPurify`, and highlight code using `highlight.js`.
- Provide an inline view mode (by hiding original preview elements and injecting `div.md-viewer-inline`) and fallback to a fixed fullscreen overlay (`div.md-viewer-overlay`) with ESC support if the inline container isn't found.
- Implement the "MD" button state changes (Inactive, Loading, Active "Undo") and transition animations.

#### [NEW] [content.css](file:///Users/arakawa/brico/md-addon/content.css)
Styles for the Markdown viewer components and UI toggle button.
- Custom styling for `.md-viewer-inline` and `.md-viewer-overlay`.
- Dark theme styling base (`#1a1a2e` background, `#8ab4f8` accent).
- Transition animations (0.3s fade) and loading spinner.
- General Markdown formatting (headings, lists, blockquotes, tables, tasks).

#### [NEW] [background.js](file:///Users/arakawa/brico/md-addon/background.js)
Background service worker that receives download requests from `content.js` and performs CORS-bypassing fetches to the Google Drive download endpoints (e.g. `https://drive.google.com/uc?export=download&id=FILE_ID`) to get raw content for private/restricted files, passing the text content back to the content script.

### Assets & Libraries

#### [NEW] [marked.min.js](file:///Users/arakawa/brico/md-addon/lib/marked.min.js)
Markdown parser library.

#### [NEW] [purify.min.js](file:///Users/arakawa/brico/md-addon/lib/purify.min.js)
DOMPurify library for HTML sanitization.

#### [NEW] [highlight.min.js](file:///Users/arakawa/brico/md-addon/lib/highlight.min.js)
Highlight.js syntax highlighter library.

#### [NEW] [github-dark.min.css](file:///Users/arakawa/brico/md-addon/lib/github-dark.min.css)
Dark code syntax highlighter theme.

#### [NEW] Icons
- `icons/icon16.png`, `icons/icon48.png`, `icons/icon128.png`: Extension icons. We will generate a source icon using the image generator tool, then downscale using macOS's `sips` CLI.

## Verification Plan

### Automated/Tool Verification
- Run a validator command or check that the files are properly formatted.
- Verify manifest JSON structure.

### Manual Verification
1. Open Google Chrome.
2. Go to `chrome://extensions/`.
3. Enable "Developer mode" (top-right).
4. Click "Load unpacked" and select `/Users/arakawa/brico/md-addon`.
5. Open any Markdown file on Google Drive (e.g., in a preview overlay view URL matching `https://drive.google.com/file/d/*/view*`).
6. Click the "MD" button in the top toolbar to toggle the Markdown render.
7. Confirm that headers, bold text, code blocks (with highlighting), bullet points, and tables render correctly.
8. Verify that clicking the "Undo" button restores the original text preview.
9. Verify that ESC closes the overlay (if in overlay fallback mode).
