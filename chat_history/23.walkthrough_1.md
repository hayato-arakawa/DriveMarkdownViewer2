## Key Achievements & Implementation Details

1. **Robust Extension Configuration**: Created a manifest targeting Google Drive pages. Using `matches: ["https://drive.google.com/*"]` ensures the script is loaded and dynamically handles Single Page Application (SPA) navigation.
2. **Flexible Content Harvesting & Folder Previews**: Designed a multi-stage scraper in `content.js` to look for code containers (`<pre>`), text page class-names, and inline styles. Added background fetching support via Google API. Also enabled file ID resolving through URL query parameters (e.g. `preview=FILE_ID`), making the extension compatible with previews opened inside folder directories (`https://drive.google.com/drive/u/*/folders/*`).
3. **Safe & Premium Markdown Engine**: Loaded official offline-first minified releases of `marked.js` (GFM), `DOMPurify` (sanitization), and `highlight.js` (dark-theme code blocks). Included a regex-based offline parser fallback.
4. **Intuitive UI Button & Dynamic Injection**: Injected a clean "MD" toggle button inside the Drive toolbar. Supported active ("元に戻す"), inactive, loading, and error UI states. Scoped all toolbar DOM lookups to the active preview overlay dialog, avoiding mismatches with the main page header. Programmatically inserts the MD button as a top-level sibling next to the "Open with" (`div.fS6dGb`) dropdown, maintaining clean layout hierarchy and avoiding deep nesting.
5. **Inline Parent-Hierarchy Rendering**: Integrated smooth 0.3s CSS transition animations and direct inline rendering. Rather than using full-screen overlay modals, the extension finds the original text node, hides it, and injects the Markdown element directly into its parent element (one hierarchy level above the original text), inheriting all correct sizing and scroll parameters naturally.

## File Structure Created

The following files have been initialized inside your extension directory [md-addon](file:///Users/arakawa/brico/md-addon/):

- `manifest.json`: Configuration for content script injections, permissions, metadata, and service worker.
- `content.js`: Main content logic monitoring toolbar insertion, scraping DOM, calling background scripts, compiling GFM, and injecting the rendered output.
- `content.css`: Custom stylesheet styling headers, lists, code, tables, layouts, transitions, spinner, and errors.
- `background.js`: Service worker receiving content requests to fetch file contents securely bypassing CORS.
- `icons/`:
  - `icon16.png`, `icon48.png`, `icon128.png` (scaled icons).
- `lib/`:
  - `marked.min.js`, `purify.min.js`, `highlight.min.js`, `github-dark.min.css`.

## How to Install and Test

1. Open **Google Chrome**.
2. Navigate to `chrome://extensions/`.
3. Enable **Developer mode** using the toggle switch in the top-right corner.
4. Click **Load unpacked** in the top-left corner.
5. Select the extension directory: `/Users/arakawa/brico/md-addon`.
6. Open your **Google Drive** and double-click any `.md` or `.markdown` file to preview it.
7. Click the **MD** button in the preview window toolbar to render the formatted Markdown content!
8. Click **元に戻す** to revert back to the original text view.
