## 🛠️ Changes Made

### 1. Extension Manifest (`manifest.json`)
Created [manifest.json](file:///Users/arakawa/chrome-md-tool/manifest.json) using the **Manifest V3** format.
- Matches `drive.google.com/file/*`, `docs.google.com/file/*`, and the `googleusercontent.com` origin where raw preview text frames are served.
- Configured `"all_frames": true` and `"match_about_blank": true` to ensure the content script injects successfully into the preview iframes.
- Injects vendor libraries and extension scripts in sequence:
  1. `lib/marked.min.js` (Markdown parsing)
  2. `lib/dompurify.min.js` (DOM sanitization)
  3. `lib/prism.js` (Code syntax highlighting)
  4. `content.js` (Extension core execution)

### 2. Vendor Libraries (`lib/`)
Successfully downloaded stable minified versions of critical third-party libraries into [lib/](file:///Users/arakawa/chrome-md-tool/lib):
- [marked.min.js](file:///Users/arakawa/chrome-md-tool/lib/marked.min.js)
- [dompurify.min.js](file:///Users/arakawa/chrome-md-tool/lib/dompurify.min.js)
- [prism.js](file:///Users/arakawa/chrome-md-tool/lib/prism.js)
- [prism.css](file:///Users/arakawa/chrome-md-tool/lib/prism.css)

### 3. Extension Core Stylesheet (`content.css`)
Created [content.css](file:///Users/arakawa/chrome-md-tool/content.css) to build a beautiful visual system:
- **GFM Layout styles:** Typography (Inter font fallback), header borders, spaced paragraphs, clean blockquotes, customized tables (with alternating stripes), list elements, and inline/block code styling.
- **Glassmorphic Floating Action Bar:** Capsules floating in the top-right corner with subtle drop shadows, backdrop-filter blur, tooltip micro-animations, and theme icons.
- **Dynamic Slide-out Outline Panel:** Hidden sidebar that slides in from the right when the Table of Contents button is active, adjusting the width of the main content dynamically.
- **Responsive Dark/Light styling:** Implemented CSS variables to automatically shift theme values depending on system settings or Google Drive's active visual theme.

### 4. Extension Core Logic (`content.js`)
Created [content.js](file:///Users/arakawa/chrome-md-tool/content.js):
- **Self-Healing DOM Checker:** Regularly scans (and observes via `MutationObserver`) for `<pre>` elements containing file content. This works dynamically without reloading the page when clicking between files.
- **Markdown Auto-detection:** Auto-enables the Markdown viewer when opening `.md` extensions, or if the text contents match markdown headers (`#`) or front-matter (`---`).
- **Sanitized Rendering:** Utilizes `marked.js` combined with `DOMPurify` to parse and render clean HTML safely, preventing extension security warnings.
- **Interactive Outline Panel (ScrollSpy):** Queries headers (`H1` to `H4`) to construct an interactive Table of Contents. Features scrollspy capability using `IntersectionObserver` to automatically highlight the current heading in the sidebar while reading.
- **Persistent Toolbar Options:** Toggles Markdown / Raw modes, opens/closes the TOC, and switches theme preferences (`Light`, `Dark`, `Auto`). Preferences are cached in `localStorage` for future previews.

### Option B: Load the Extension in Chrome
Once you've verified the mockup, you can load the unpacked extension in Chrome to use it directly in Google Drive:

1. Open Chrome and go to `chrome://extensions/`.
2. In the top-right corner, toggle the **Developer mode** switch on.
3. Click the **Load unpacked** button in the top-left corner.
4. Select the directory: `/Users/arakawa/chrome-md-tool` and click **Select**.
5. Go to your **Google Drive** (`https://drive.google.com/`) and open any `.md` file. The extension will automatically format and display the Markdown file inside the preview screen.
