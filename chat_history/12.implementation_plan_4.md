# Implementation Plan - Google Drive Markdown Preview Chrome Extension

This plan outlines the design and implementation of a Chrome extension that detects plain-text Markdown files inside the Google Drive preview viewer (`https://drive.google.com/file/*`) and renders them as beautiful, styled Markdown documents with syntax highlighting, a floating control panel, and a dynamic Table of Contents (TOC).

## User Review Required

> [!IMPORTANT]
> **Manifest V3 and Origin Isolation:** 
> Google Drive renders text previews inside subdomains like `docs.google.com` or `*.googleusercontent.com` inside an `iframe`. To access the `<pre>` tag containing the raw text, the content script must run inside all frames (`"all_frames": true`) and have permissions for `https://drive.google.com/*`, `https://docs.google.com/*`, and `https://*.googleusercontent.com/*`.
> 
> **No External CDNs:** 
> According to Chrome Extension Manifest V3 security policies, we cannot load external scripts (like `marked.js` or `DOMPurify` via CDN) at runtime. We will bundle these vendor scripts locally in a `lib/` directory inside the extension.

## Proposed Features for a Premium Experience
1. **Seamless Integration:** Run inside the Google Drive preview frames, locating the `<pre>` element dynamically using a `MutationObserver`.
2. **Beautiful Markdown Rendering:** Render GitHub Flavored Markdown (GFM) using `marked` and sanitize it with `DOMPurify`.
3. **Syntax Highlighting:** Format code blocks beautifully using `PrismJS`.
4. **Floating Control Bar (Glassmorphic):** A sleek, modern floating action toolbar with:
   - **Toggle View:** Switch between "Rendered Markdown" and "Raw Text".
   - **TOC Toggle:** Toggle a slide-out Table of Contents panel for quick heading navigation.
   - **Theme Selector:** Light, Dark, or System Sync (automatically reads Google Drive's active theme or browser scheme).
5. **Auto-detection:** Automatically enable Markdown rendering if the filename ends with `.md`/`.markdown` or if the text contains obvious Markdown structure (e.g. headers, lists, links).

### [NEW] manifest.json

Create the Chrome extension manifest using Manifest V3.
- Matches `drive.google.com`, `docs.google.com`, and `googleusercontent.com`.
- Sets `"all_frames": true` to inject into the preview frames.

### [NEW] content.js

This script will:
1. Run in all frames and monitor for a `<pre>` element.
2. Detect if the content is Markdown (based on file title or contents).
3. If Markdown is detected, insert a premium floating toolbar.
4. Render the Markdown dynamically using the local libraries (`marked` and `DOMPurify`).
5. Support a Table of Contents sidebar for easy navigation.
6. Observe dark mode preference to match Google Drive's native dark theme.

### [NEW] content.css

A comprehensive CSS stylesheet containing:
- Glassmorphic floating toolbar styles.
- Smooth transition animations (fade-in, slide-out for the TOC).
- Premium Markdown styling (GitHub-like typography, spacing, tables, blockquotes).
- Dark mode theme styles that match Google Drive's exact look and feel.

### [NEW] lib/

Download and place the following open-source libraries:
- `marked.min.js` (Markdown parsing)
- `dompurify.min.js` (HTML Sanitization)
- `prism.js` & `prism.css` (Syntax highlighting)

### [NEW] icons/

Create programmatically generated or SVG-based extension icons.

## Verification Plan

### Automated / Semi-Automated Verification
- Verify `manifest.json` schema validation using Chrome Extension developer portal or local loading.
- We will write a test environment or mockup page matching Google Drive's preview DOM in the `scratch/` directory to verify the parsing, rendering, GFM styling, and TOC behaviors locally before packing.

### Manual Verification
1. Open Chrome and go to `chrome://extensions/`.
2. Enable "Developer mode".
3. Click "Load unpacked" and select the extension directory.
4. Open Google Drive and click on a Markdown file (`.md`).
5. Confirm that:
   - The file renders as beautiful HTML instead of raw text.
   - The floating toolbar is visible and lets the user toggle between raw and rendered markdown.
   - The Table of Contents navigation works when clicking links.
   - Theme toggle successfully shifts between Light and Dark mode.
